## 2024-10-24 - Interactive DIVs need semantic roles and keyboard handlers
**Learning:** Using `div` elements for interactive cards like `.book-card` creates an immediate accessibility barrier for keyboard and screen reader users. Simply adding an `onclick` handler does not make it accessible. It requires `role="button"`, `tabindex="0"`, and custom keydown handlers (for Enter/Space) to properly mimic button behavior. Also, custom modals often miss the `Escape` key close pattern and `aria-label`s on icon-only close buttons.
**Action:** Next time I encounter a `div` or non-interactive element being used as a button, I will convert it to an actual `<button>` if possible, or immediately apply `role="button"`, `tabindex="0"`, and `keydown` handlers along with `:focus-visible` styles to ensure it remains fully accessible.
