# Barrioteca Acalencá - SLiMS

Código fuente de SLiMS (Senayan Library Management System) personalizado para la **Barrioteca Acalencá**. Este sistema ha sido adaptado para funcionar como una biblioteca autogestionada, independiente y vecinal, con una interfaz feminizada y una API integrada para la PWA.

## Personalizaciones
- **Interfaz Feminizada**: Adaptación de términos en todo el sistema (Socia, Autora, Bibliotecaria).
- **API v1**: Endpoints personalizados para la integración con la aplicación móvil.
- **Catalogador ISBN**: Módulo propio para buscar libros por ISBN en Google Books, Open Library y el Ministerio de Cultura de España, sin dependencias externas complejas.
- **Optimización para Synology**: Configuración ajustada para entornos NAS con MariaDB.
